## 尚未替代的外部验证

自动化测试只能证明产品行为正确，不能替代业务用户访谈。提交前建议至少邀请 3 名熟悉定制或职业服业务的人员完成以下任务。

### 任务 A：私定需求整理

输入一段口语化见客外套需求，要求参与者：

1. 找出系统错误确认或遗漏的字段。
2. 判断首个版型基线是否合理。
3. 判断提示词能否直接交给视觉设计。
4. 指出台账中仍需人工补全的内容。

### 任务 B：团体职业服方案

输入岗位、人数、场景和抗皱要求，要求参与者：

1. 判断资源分类是否能覆盖职业服工作流。
2. 判断岗位分区放量是否可执行。
3. 判断台账是否足够用于业务复盘。

## 建议记录指标

- 从客户原话到可交付需求所需的追问轮数。
- 单次访谈整理时间，对比人工文档整理。
- 已确认字段完整率。
- 企业资产复用次数与命中率。
- 顾问接手时需要重新补问的问题数量。
- 台账导出后仍需人工复制信息的次数。

## 验收门槛

- 业务访谈中，品类错配为 0。
- 已确认字段不会被 AI 建议覆盖。
- 顾问接手后无需重新录入需求、面料、版型或提示词。
- 视觉提示词中不出现未确认占位符。
- 所有最终商务动作均明确标注为人工确认。
