# Agent 能力边界清单

## Agent 可以完成

- 记录客户原话并归纳为结构化定制需求。
- 区分客户已确认信息、AI 建议和仍待确认字段。
- 从企业模拟版型、面料、工艺与案例中检索并解释匹配理由。
- 组合参考方案初稿，提示风险、差距和需要复核项。
- 生成标准化视觉提示词和企业静态参考图。
- 生成包含资源快照、参数、打样状态与操作留痕的台账草稿。

## Agent 不可以完成

- 不给出正式价格、折扣、合同条款或交期承诺。
- 不替代版师确认最终版型、纸样、放码或工艺单。
- 不执行生产下单、采购、库存锁定或供应商指令。
- 不执行客户照片试穿、身份推断或体型诊断。
- 不连接真实 CRM、生产系统或客户业务 API。
- 不虚构企业没有提供的资源、历史案例或产能。
- 不把 AI 建议自动视为客户确认。

## 人工必须完成

- 客户身份、授权与联系信息确认。
- 面料实物、色卡、缩率和批次确认。
- 版型定稿、样衣试身与工艺风险签核。
- 报价、商务谈判、合同、交期与生产决策。
- 团体职业服岗位比例、尺码分配和发放规则确认。

## 数据与合规

- 原型仅使用模拟静态企业资产和用户主动填写的信息。
- 联系人信息仅用于本次模拟承接。
- 当前原型本地台账未做生产级权限、加密、留存期限和审计接入，不能直接用于真实客户数据。
- 正式上线前需补充隐私告知、最小化采集、访问控制、删除机制和数据脱敏。
