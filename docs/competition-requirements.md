# DOAI FDE-03 命题逐条对应

命题：上服集团「海派定制服饰 AI 需求解构与可视化 Agent」

## 1. 命题定位

| 命题要求 | 当前实现 | 证据 |
| --- | --- | --- |
| Agent 是定制业务辅助助手 | 顶栏明确为「上服定制业务协作台」，系统提示词限定服务业务专员、方案设计师和企划人员 | `src/app/api/chat/route.ts`、`src/components/studio-app.tsx` |
| 覆盖高端私定与团体职业服 | 首屏可切换业务类型，并内置两套完整模拟案例 | `DEMO_CASES`、`quick demo` 截图 |
| 降低沟通成本、复用存量资产、沉淀案例 | 确认态需求、四类资产检索、资源快照和操作留痕 | `src/lib/brief.ts`、`qa/e2e-report.json` |

## 2. 核心能力与输出物

| 要求输出物 | 当前实现 |
| --- | --- |
| 可检索定制资产知识库、资源分类清单 | 版型 / 面料 / 工艺 / 案例四类资产，支持关键词检索和场景标签 |
| 六维需求结构化清单、情绪审美标签报告 | 按「场景与规模 / 轮廓与比例 / 领型与纹样 / 面料与色彩 / 活动与体感 / 禁忌与边界」分组展示 14 个字段；每项明确已确认或待确认 |
| 海派定制方案初稿、资源匹配说明、可行性提示 | 方案初稿汇总风格定位、轮廓结构、面料方向、领型衣长、工艺组合、适用场景与设计亮点；同时展示匹配分、差距项和风险提示 |
| 成套 AI 视觉提示词、视觉效果需求包 | 拆分成衣效果、工艺细节、上身穿搭三套提示词；只使用已确认字段，企业基线单独标注为参考，可复制单套、复制三套或导出 |
| 可编辑、可上报的定制业务专题台账 | 交付页可直接填写业务台账备注；Markdown 台账与完整 JSON 交接包包含六维需求、审美标签、方案初稿、三套提示词、资源快照、打样状态和时间线 |

## 3. 业务边界

| 边界 | 实现 |
| --- | --- |
| 不执行最终业务决策 | 版型、报价、交期、合同和生产由人工完成 |
| 只使用模拟静态数据 | 资源文件位于 `public/assets`，交接写入 `data/handoffs/` |
| 不连接真实生产或业务 API | 图像和 LLM 是可替换适配层；业务系统未接入 |
| 视觉结果需标明来源 | 实时生成与静态企业资产在界面和台账中明确区分 |

## 5. 决赛表达重点

评委按技术创新性、商业可行性、产业适配度、团队与落地力评估，其中本赛道重点看真实业务需求匹配度。

演示必须依次证明：

1. 客户原话能被解构成六维结构，并区分确认事实和待确认建议。
2. 品类是进入设计的硬门槛，必须确认品类和至少 3 个设计相关字段；外套不会被匹配成衬衫，没有同品类资产时会明确停止推进。
3. 企业版型、面料、工艺和案例能检索并说明匹配理由。
4. 方案初稿、审美标签报告和成衣效果 / 工艺细节 / 上身穿搭三套提示词都能在页面上直接看到并复制。
5. 视觉提示词不补写未确认的领型、面料或色彩；企业默认值只作为单独标注的参考。
6. 顾问可以在应用内填写台账备注，最终输出是一份可直接接手、可追溯、可上报的业务成果。
